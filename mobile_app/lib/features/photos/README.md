# Feature: Photos

Phân hệ quản lý và xem ảnh mốc nhà giao hàng:

- `customer_photos_strip_widget.dart`: Thanh cuộn ngang hiển thị các ảnh thực tế của mốc nhà gắn liền với khách hàng, hỗ trợ chụp ảnh mới từ camera, chọn ảnh từ thư viện thiết bị và xóa ảnh.
- `fullscreen_image_viewer.dart`: Trình xem ảnh toàn màn hình chất lượng cao hỗ trợ thao tác zoom 2 ngón tay (pinch-to-zoom) và xoay ảnh.
