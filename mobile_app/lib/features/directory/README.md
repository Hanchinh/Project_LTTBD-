# Feature: Customer Directory

Phân hệ danh bạ khách hàng lưu trữ cục bộ:

- **Views**:
  - `customer_directory_view.dart`: Danh bạ khách hàng toàn diện với thanh tìm kiếm thời gian thực, lọc theo khu vực và trạng thái đã có mốc/chưa có mốc.
  - `customer_detail_edit_view.dart`: Màn hình xem chi tiết và chỉnh sửa thông tin khách hàng, số điện thoại, ghi chú và địa chỉ.
- **Widgets (`widgets/`)**:
  - `customer_list_item.dart`: Thẻ hiển thị khách hàng trong danh bạ với thao tác gọi nhanh, ghim mốc và điều hướng.
  - `directory_filter_tabs.dart`: Thanh tab lọc danh bạ nhanh theo khu vực phụ trách.
  - `directory_header.dart`: Thanh tiêu đề danh bạ kèm nút thêm nhanh và công cụ dán SĐT.
