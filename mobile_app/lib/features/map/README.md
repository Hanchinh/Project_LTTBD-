# features/map
Bản đồ chính hiển thị điểm ghim khách hàng và công cụ định vị thực địa.

- `main_map_view.dart`: Màn hình bản đồ trung tâm, hiển thị shipper và các điểm giao.
- `main_map_view_handlers.dart`: Xử lý sự kiện chạm, chuyển tab và tương tác bản đồ.
- `crosshair_location_picker_view.dart`: Màn hình tâm ngắm ghim vị trí chuẩn xác.
- `widgets/`: Bộ điều khiển map, tâm ngắm, thẻ thông tin điểm, và cụm marker.
